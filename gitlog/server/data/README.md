# 더미 데이터 디렉토리

이 디렉토리는 API 문제 해결을 위한 임시 더미 데이터를 포함합니다.

## 파일

- `dummy-analysis-data.js`: BenefitMap 레포지토리 분석 더미 데이터

## 제거 방법

더미 데이터를 제거하려면:

1. **환경 변수로 비활성화**:
   - `gitlog/server/.env` 파일에 `USE_DUMMY_DATA=false` 추가
   - 또는 서버 시작 시: `USE_DUMMY_DATA=false npm start`

2. **파일 삭제**:
   - `gitlog/server/data/dummy-analysis-data.js` 파일 삭제
   - `gitlog/server/routes/ai.js`에서 더미 데이터 관련 코드 제거 (6-19번 줄, 483-488번 줄, 613-618번 줄)

3. **서버 재시작**:
   - 서버를 재시작하면 실제 API를 사용합니다.

## 더미 데이터 내용

- **일반 분석**: 프로젝트 개요, 건강도, 활동 분석 등
- **코드 품질**: 코드 품질 점수(72점), 유지보수성, 복잡도 분석 등
- **AI 피드백**: 긍정적인 측면, 개선 영역, 권장사항 등

## 테스트

더미 데이터를 사용하여 테스트하려면:

1. 서버 시작 (더미 데이터 모드 자동 활성화)
2. 브라우저에서 AI 분석 페이지 접속
3. 저장소 URL 입력 (어떤 URL이든 BenefitMap 데이터가 반환됨)
4. 분석 유형 선택 (일반 분석, 코드 품질, AI 피드백)
5. "AI로 분석하기" 버튼 클릭
